# CyberBud: Browser Extension
**What is it?** 
CyberBud is a browser extension made to facility the life of security analyst or tech users who like to navigate the web safely.
It brings all the reputation checks directly into the webpage, without need to jump around tabs and websites, copying IOC's around.

**Who is it for?**
This tool was made for tech oriented people. It provides raw analysis from the integrated platforms and requires user setup of BYOK.
